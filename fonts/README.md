# Bundled typefaces

`render_preview.py` uses Segoe UI and Consolas where they are installed, and these open stand-ins otherwise, so the inspection sheet can be regenerated on any machine. They are third-party works, unmodified, licensed under the SIL Open Font License 1.1 (texts beside each font).

| File | Typeface | Stands in for | Source |
| --- | --- | --- | --- |
| Selawik-Regular.ttf, Selawik-Semibold.ttf | Selawik | Segoe UI | microsoft/Selawik release 1.01 (`selawk.ttf`, `selawksb.ttf`) |
| Inconsolata-Variable.ttf | Inconsolata | Consolas | google/fonts, `ofl/inconsolata/Inconsolata[wdth,wght].ttf` |
