# Revision B engineering basis

Meridian is a 3.3 V, nonisolated, bench integration carrier. It provides an RS-485 port, SPI and I²C expansion, two analog inputs, and two low-side outputs. The controller, firmware and peripherals are external to this board.

| Decision | Basis and implementation |
| --- | --- |
| Lower-speed RS-485 device | U1 uses the pin-compatible 500 kbps THVD1410 in the SOIC D package. The shared DIR signal drives active-high DE and active-low RE. R1 holds the transceiver in receive mode at reset. C1 and C2 bypass the supply close to U1. [TI device and layout guidance](https://www.ti.com/product/THVD1410) |
| Termination at the cable end | JP1 connects R2 across A and B. Fit it at a cable end when this board provides the cable termination. Leave it open on a stub or when termination is already present. U1 provides open, short and idle bus fail-safe behavior at the receiver. Board-level surge and immunity qualification are separate measurements. [TI RS-485 design guide](https://www.ti.com/lit/an/slla272d/slla272d.pdf) |
| Explicit supply selection | JP3 selects either J1 controller power or regulated J7 auxiliary power. The center pin feeds the carrier. No source is selected with the shunt removed. Do not bridge both positions. Keep all connected logic powered and compatible with the same 3.3 V reference to avoid backfeed through signal pins. |
| Analog bandwidth | Each 1 kΩ and 100 nF section has a nominal time constant of 100 μs and a corner frequency of about 1.59 kHz. The external controller determines ADC acquisition timing, input impedance and full-scale range. Validate settling at the intended sampling rate before setting an accuracy target. [TI SAR ADC front-end guidance](https://www.ti.com/video/5476574757001) |
| Pull-ups and load outputs | JP2 connects two 4.7 kΩ I²C pull-ups. Keep it open when the existing bus already meets rise-time and sink-current needs. The AO3400A outputs sink current only. The bench qualification uses low-voltage resistive loads. An external inductive load needs its own suppression. [AO3400A data sheet](https://www.aosmd.com/sites/default/files/res/data_sheets/AO3400A.pdf) |
| Header mechanics | The nominal 1.05 mm plated drill leaves insertion allowance for 0.64 mm square posts. The pad is 1.75 mm. Confirm the finished hole tolerance, plating, and mating connector with the chosen parts and fabricator. [Samtec TSW header family](https://www.samtec.com/products/tsw) |
| Return and supply paths | L2 is reserved for ground and L3 for 3.3 V copper. Signals stay on the outer layers. Supply and load traces use 0.508 mm copper, and signal traces use 0.254 mm. The stack targets a standard 1.60 mm four-layer FR-4 board. Confirm the final stack with the selected fabricator. [Example fabrication capabilities](https://jlcpcb.com/capabilities/Capabilities) |
| Handoff verification | The source net map drives schematic and layout. Native KiCad ERC, DRC, and a netlist comparison are the CAD checks. Hardware bring-up, an independent footprint-to-part review, and approval of the fabricator quote are separate release decisions. [KiCad CLI reference](https://docs.kicad.org/10.0/en/cli/cli.html) |

The layout targets short, referenced bench wiring. It has no controlled-impedance commitment. Nominal values in this document are design inputs and calculations. The [bring-up plan](bring-up.md) records the measurements still to take.
